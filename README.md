# Yasmenum — website

Public pages for the Yasmenum app (iOS and Android): privacy policy, terms of use and support, in English and Czech. Served with GitHub Pages at https://janhrdonka.github.io/yasmenum/.

The app source code is private; this repository holds only these static pages.

## Before release
- Fill in the operator (company name, registered office, IČO, registry entry) and the support e-mail: search for `TODO(s.r.o.)`.
- Re-check the privacy policy whenever the apps' data handling changes (Play Billing, backups, Screen Time).
